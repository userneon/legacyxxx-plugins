# Future CounterStrikeSharp Runtime Layout

This directory is a **source-control placeholder only**. Do not commit a real `.env`, DLL, CounterStrikeSharp installation, game-server binary, or runtime-generated config here.

When a future CS2 host exists, its central secret file belongs at `CounterStrikeSharp/.env`. Compiled modules are packaged with `./scripts/package.sh` into `dist/legacyx-cs2/` (runtime files only, mirroring `game/csgo/`); see the root README for the layout.
