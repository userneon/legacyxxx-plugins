# Future CounterStrikeSharp Runtime Layout

This directory is a **source-control placeholder only**. Do not commit a real `.env`, DLL, CounterStrikeSharp installation, game-server binary, or runtime-generated config here.

When a future CS2 host exists, its central secret file belongs at `CounterStrikeSharp/.env`. Compiled module artifacts will be copied from source build output into the actual host's CounterStrikeSharp plugin directories by a reviewed packaging/deployment procedure.
